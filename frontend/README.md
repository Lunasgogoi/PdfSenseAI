# PdfSense frontend

The responsive React client for PdfSense. It provides PDF upload, local document selection, cited chat, summaries, MCQs, and flashcards.

```powershell
npm install
npm run dev
```

Use `npm test`, `npm run lint`, and `npm run build` for the quality gate. Full setup, API documentation, and architecture notes live in the [project README](../README.md).
